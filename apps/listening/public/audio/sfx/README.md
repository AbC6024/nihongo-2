# 音效素材來源與授權紀錄

## 現況：目前資料夾內**沒有任何音效檔案**

| 檔案 | 狀態 |
| --- | --- |
| `correct.mp3` | **不存在** |
| `wrong.mp3` | **不存在** |
| `skip.mp3` | **不存在** |
| `game-over.mp3` | **不存在** |

本專案**沒有匯入任何第三方音效素材**（包含 Pixabay、Freesound、
Mixkit、Zapsplat 等來源）。原因：

1. 無法在這個環境中確認每個素材目前的授權條款，
   尤其「商業用途」與「再散布」條款各站不同。
2. 免費不代表可任意再散布；在授權未確認前散布不負責任。
3. 下載二進位檔案後無法在本專案內留存可稽核的授權證明。

**因此沒有假裝外部音效已匯入。**

## 目前實際使用的音效：Web Audio API 即時合成

提示音效由 `src/services/sfx.ts` 在執行時用 Web Audio API 合成：

- 不依賴任何外部檔案或第三方網站。
- 無授權風險（由本專案自行產生）。
- 載入失敗機率為 0，不會影響答題流程。
- 檔案體積增加 0 KB。

各音效的設計：

| 音效 | 合成方式 | 長度 |
| --- | --- | --- |
| `correct` | 880 Hz → 1320 Hz 兩段上行三角波 | 約 180 ms |
| `wrong` | 330 Hz → 262 Hz 兩段下行正弦波（音量刻意偏低） | 約 220 ms |
| `skip` | 520 Hz → 440 Hz 單段下滑音 | 約 130 ms |
| `gameover` | 784 → 587 → 440 Hz 三音結算音 | 約 330 ms |

所有音效都使用快速起音 + 指數衰減的包絡，避免爆音。

## 日後要換成實體音檔時

1. 取得**可再散布**的授權（確認商業用途與再散布條款）。
2. 把檔案放在本資料夾，並在下方表格補上來源、作者、授權名稱、
   授權網址與下載日期。
3. 若要求標示作者，必須在產品內顯示（建議放在遊戲設定頁底部）。
4. 修改 `src/services/sfx.ts`：在 `playSfx()` 開頭改為播放音檔，
   或新增檔案型音效的播放分支，保留目前的合成音作為載入失敗時的備援。

## 與題目語音的關係

- 提示音效**只**在 `playSfx()` 中產生。
- 題目的日文發音走 `src/services/speech.ts`，兩者完全獨立。
- 關閉音效（設定中的「答題提示音效」）**不會**關閉題目語音。
- 答錯時音效與題目重播之間有 260 ms 間隔（`SFX_SPEECH_GAP_MS`），
  避免兩者重疊刺耳。
